# Upstream preservation

No original source modifications were made during preservation. As of repository
finalization, `hackshift/projects/project-1` and `hackshift/projects/project-2` have been
fully retired and removed from the active repository to leave only the production AYUSETU
codebase.

Publication excludes an existing populated SQLite database (provenance not
established), historical authenticated JWT penetration-test scripts, captured test
logs, dependency/build caches and environment files. These files are retained
locally without modification. Anonymous browser Supabase keys are public client
configuration, not privileged service credentials. No requests to that hosted
Supabase instance are authorized or performed by the unified demo.

`baseline-untouched` records the publishable original source. Verification compares
all tracked original files and detects new source files, including ignored source
additions. There are no allowlisted source edits.
