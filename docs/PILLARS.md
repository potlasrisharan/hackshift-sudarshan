# Pillars and honest demo measures

| Pillar | Shipped slice | Measure | Demo moment | Limit |
|---|---|---|---|---|
| Accessibility | Four interface dictionaries; large text; dark mode; responsive PWA; shared offline algorithms; native mobile source | Browser tests cover Hindi label, 390px layout and offline Sentinel; web JS ~37 KB gzip | Switch Hindi, large text and dark mode, then disconnect network in the lab | Voice provider and fully translated clinical UI are pending |
| Affordability | Course-valid cross-clinic stock allocation with integer paise and transfer cost | Demo: North ₹120 vs East+transfer ₹64; synthetic difference ₹56 | Open Medicine access; rejected cheap expiry and wrong-strength batches are explained | No live market prices or actual savings claim |
| Quality | Validated adapters; consent enforcement; provenance; source-linked template summary; deterministic engines; audit verification | Passing unit/property/API/browser suites; real mechanism benchmark JSON | Export FHIR, inspect citations, trigger red flag, revoke consent | No clinical validation, ABDM certification or production immutability |

Benchmark counts and timings are generated in benchmarks/results.json. Tests are
engineering evidence only. No patient outcomes, clinical accuracy or real cost
savings have been measured.
