## Six minutes

0:00–0:40 — “Care breaks when information is handed from intake to the clinic and
then home.” Begin a synthetic Sunita session. Explain explicit local consent.

0:40–1:30 — Switch Hindi, large text and dark mode. Open Patient Thread: one
measurement has a Project 1 source and one a Project 2 source. Explain that these
are adapter fixtures, not a live database connection. Create the source-cited
summary and export the FHIR collection.

1:30–2:30 — Open Medicine access. Show the cheapest expiring batch rejected and
the wrong-strength batch rejected. Compare North ₹120 with East plus transfer
₹64. This is synthetic pricing, not proven savings. Open the exact allocation.

2:30–3:20 — Show Home monitoring. A personal robust baseline and a CUSUM trace
explain the upward synthetic BP shift. Clarify that it is not clinically validated
and that absolute danger handling is separate.

3:20–4:20 — Algorithm Lab: trigger the affirmative chest-pain test. Show the
emergency message and the API/local-result comparison. Explain independent
refill probability convolution and the manager-approved inventory suggestion.

4:20–5:15 — Privacy: inspect storage limitations, verify the hash chain, export or
revoke. Revocation returns to consent and the API denies record access. No
claim of encrypted durable storage or system-wide zero-egress proof is made.

5:15–6:00 — Show generated benchmark JSON, passing tests, mobile source/build
status and optional local Cognee verification if it completed. Explain blockers:
live upstream identity/data, provider keys, real devices and AWS authentication.

## Two minutes

Begin consent → shared source timeline → medicine course-validity rejection and
₹64 plan → red-flag lab → audit verification and revoke. Close with exactly what
was tested, not a copied PRD performance claim.

## Offline fallback / backup recording

Open the lab once while connected, then disconnect: local engine still runs.
The full API does not become offline durable storage. Keep the same platform
running locally in case venue Wi-Fi fails. Record a 6-minute and 2-minute browser
walkthrough using the OS screen recorder; show the Demo data badge and readable
terminal test output, avoid credentials, and retain a local MP4. No backup video
